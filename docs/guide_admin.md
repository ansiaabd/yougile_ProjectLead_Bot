# Инструкция для администратора

Telegram-бот для задач. Двусторонняя синхронизация с Yougile.

---

## Полные возможности

Администратору доступно всё: команды исполнителя, модератора и админские.

### Команды исполнителя

| Команда        | Что делает            |
| -------------- | --------------------- |
| `/add`         | Создать задачу        |
| `/list`        | Мои активные задачи   |
| `/take <ID>`   | Взять задачу в работу |
| `/done <ID>`   | Отметить выполненной  |
| `/delete <ID>` | Удалить задачу        |
| `/overdue`     | Просроченные задачи   |
| `/cancel`      | Отменить создание     |

### Команды модератора

| Команда | Что делает |
|---|---|
| `/pending` | Все задачи на подтверждении |
| ✅ **Подтвердить** | Задача → «Готово», Yougile → доска **«Готово»** |
| ❌ **Отклонить** | Задача → активна, Yougile → доска **«В работе»** |

### Админ-команды

| Команда                  | Что делает                                |
| ------------------------ | ----------------------------------------- |
| `/list all`              | Все активные задачи всех пользователей    |
| `/users`                 | Список всех пользователей с ролями и ID   |
| `/promote <ID>`          | Назначить модератором                     |
| `/demote <ID>`           | Снять модератора                          |
| `/removeuser <ID>`       | Удалить пользователя                      |
| `/link_email <email>`    | Привязать пользователя к Yougile по email |
| `/setup_project`         | Создать доски в проектах Yougile          |
| `/create_project <name>` | Создать новый проект в Yougile            |
| `/setup_webhooks <URL>`  | Настроить вебхуки Yougile                 |
| `/help`                  | Справка                                   |

---

## Особенности админа

- Админ отмечает `/done` → задача сразу выполнена (без подтверждения)
- Админ может подтверждать и отклонять **любые** задачи
- Админ может отмечать `/done` чужие задачи

---

## Синхронизация с Yougile

### Что происходит при действиях

| Действие в боте | Статус задачи | Доска в Yougile |
|---|---|---|
| Создали `/add` | active | Задачи |
| Взяли в работу `/take` | active | В работе |
| Исполнитель отметил `/done` | pending_approval | На проверке |
| Админ отметил `/done` | done | Готово |
| Админ подтвердил ✅ | done | Готово |
| Админ отклонил ❌ | active | В работе |

### Настройка интеграции (для нового проекта)

1. Создай проект в Yougile
2. В Telegram: `/setup_project` — создаст доски «Задачи», «В работе», «На проверке», «Готово»
3. Пользователи привязывают email: `/link_email user@email.com`
4. Настрой вебхуки: при смене IP сервера `/setup_webhooks http://43.245.226.45:8787`
