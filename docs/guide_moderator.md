# Инструкция для модератора

Telegram-бот для задач. Синхронизация с Yougile.

---

## Твои возможности

Модератор может всё, что обычный исполнитель, плюс:

| Команда | Что делает |
|---|---|
| `/pending` | Показать задачи, ожидающие твоего подтверждения |
| ✅ **Подтвердить** | Задача выполнена, Yougile → доска **«Готово»** |
| ❌ **Отклонить** | Задача возвращается в работу, Yougile → доска **«В работе»** |

---

## Как подтверждать задачи

1. Когда исполнитель отмечает задачу `/done`, тебе приходит уведомление
2. Нажми **✅ Подтвердить** или **❌ Отклонить**
3. Если отклоняешь — бот попросит написать причину, она отправится в Yougile как комментарий

**Важно:** Модератор видит в `/pending` только те задачи, которые **сам создал**.

---

## Команды исполнителя (тоже доступны)

| Команда | Что делает |
|---|---|
| `/add` | Создать задачу |
| `/list` | Мои активные задачи |
| `/take <ID>` | Взять задачу в работу |
| `/done <ID>` | Отметить выполненной |
| `/delete <ID>` | Удалить задачу |
| `/overdue` | Просроченные задачи |
| `/cancel` | Отменить создание |
| `/help` | Справка |

---

## Как стать модератором

Администратор назначает командой `/promote <ID>`.
