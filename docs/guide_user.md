# Инструкция для исполнителя

Telegram-бот для задач. Синхронизация с Yougile.
**Бот**: @My_ProjectLead_Bot

---

## Как начать

1. Открой Telegram и напиши боту: **@My_ProjectLead_Bot**
2. Нажми **Start** или отправь `/start` — бот зарегистрирует тебя в системе
3. Теперь администратор может назначать тебе задачи

---

## Синхронизация с Yougile

Чтобы задачи в Yougile назначались на тебя, нужно привязать свой email:

1. Скажи администратору свой email, которым ты зарегистрирован(а) в Yougile
2. Администратор выполнит команду: `/link_email твой@email.com`
3. Готово — теперь при создании задачи через бот она автоматически назначается на тебя в Yougile

**Что синхронизируется:**
- Создание задачи → Yougile, доска **«Задачи»**
- `/take` → Yougile, доска **«В работе»**
- `/done` → Yougile, доска **«На проверке»**
- Подтверждение ✅ → Yougile, доска **«Готово»**
- Отклонение ❌ → Yougile, доска **«В работе»**
- Комментарий при `/done` → чат задачи в Yougile
- Изменения в Yougile → уведомление в Telegram
- Просроченные задачи → бот присылает напоминание

## Команды

| Команда | Что делает |
|---|---|
| `/add` | Создать задачу |
| `/list` | Мои активные задачи |
| `/take <ID>` | Взять задачу в работу |
| `/done <ID>` | Отметить выполненной |
| `/delete <ID>` | Удалить задачу |
| `/overdue` | Просроченные задачи |
| `/cancel` | Отменить создание задачи |
| `/help` | Справка |

---

## Как создать задачу

**Пошагово:**
Напиши `/add` → выбери проект → выбери исполнителя → название → описание → дедлайн

**Одной строкой (быстро):**
```
задача Название / Описание / Дедлайн / @исполнитель
задача Название / Дедлайн / @исполнитель
```

Пример:
```
задача Написать отчёт / Для клиента / завтра в 15 / @ivan
```

---

## Как взять задачу в работу

```
/take 15
```
Задача перемещается на доску **«В работе»** в Yougile.

---

## Как отметить выполнение

1. Напиши `/done 15` (или «выполнено» / «сделано» / «готово»)
2. Бот предложит отправить комментарий или файл — он попадёт в чат задачи в Yougile
3. Задача уходит на **подтверждение** админу/модератору
4. В Yougile задача перемещается на доску **«На проверке»**

**Если подтвердят** ✅ — задача выполнена, в Yougile на доске **«Готово»**
**Если отклонят** ❌ — задача снова активна, в Yougile на доске **«В работе»**

---

## Форматы дедлайна

| Как писать | Результат |
|---|---|
| `8 июня в 12` | 8 июня 12:00 |
| `завтра в 15` | завтра 15:00 |
| `сегодня в 20` | сегодня 20:00 |
| `08.06 18:30` | 8 июня 18:30 |
| `08.06.2026 16:00` | 8 июня 2026 16:00 |
